Lhotse Supercharger

Extension for managed browsers.

This endpoint hosts the self-signed build of the Lhotse Supercharger extension for organisations that install it on managed Edge or Chrome browsers through policy. New versions roll out automatically; nothing on this page ever changes.

Install

Add this entry to the ExtensionInstallForcelist policy for Edge and/or Chrome (Intune, GPO or your MDM):

bgpmhbinpaagkmpdiohnnbhfhfpilpio;https://extension.lhotse.io/update.xml
Remove the Chrome Web Store version from managed devices. This build has its own extension ID, so both would otherwise run side by side.
Off-store force-install only applies to managed (enrolled or domain-joined) devices.

Files

/update.xml
Update manifest the browser polls. Its address never changes.
/supercharger-<version>.crx
Signed package, one file per version. The current one is named inside the manifest.

How updates work

  1. The browser reads update.xml on install and every few hours afterwards.
  2. When the manifest lists a higher version than the one installed, the browser downloads that package.
  3. The signature is checked against the extension ID in your policy, then the extension is updated silently.
