Lhotse extension for managed browsers

This site hosts the self-signed build of the Lhotse Supercharger browser extension for organisations that install it on managed Edge or Chrome browsers through policy.

Files

  • /update.xml: the update manifest browsers poll. Its address never changes.
  • /supercharger-<version>.crx: the signed packages, one per version. The current one is named inside the manifest.

Install on managed devices

Add this entry to the ExtensionInstallForcelist policy for Edge and/or Chrome (Intune, GPO or your MDM). Nothing else is needed; new versions roll out automatically.

bgpmhbinpaagkmpdiohnnbhfhfpilpio;https://extension.lhotse.io/update.xml

This build has its own extension ID and is separate from the Chrome Web Store listing. Remove the store version from managed devices so users do not end up with two copies. Off-store force-install only applies to managed (enrolled or domain-joined) devices.
